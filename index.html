12 · TROUBLESHOOTING

    
막히면 여기부터 확인

    

      
속도 1~3 tok/s로 급락
→
CPU 오프로딩 · ollama ps 확인 후 3비트 파일·컨텍스트 축소

      
CUDA Out of Memory
→
컨텍스트 한 단계↓ · -fa on · q8_0 · mmproj 언로드

      
GPU 미인식, CPU로만 동작
→
최신 드라이버 · cudart 같은 폴더 · CUDA_VISIBLE_DEVICES=0

      
런처에 모델 목록 없음
→
서버 가동 확인 · /v1 추가 · host.docker.internal

      
도구 호출 실패·중단
→
--jinja · --tool-call-parser · 동적 3비트+ · 64K+ 컨텍스트

      
문맥 유실·무한 반복
→
컨텍스트 32K~64K+ · temp 1.0 / top_p 0.95 / top_k 20
