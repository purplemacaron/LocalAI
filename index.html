18 — TROUBLESHOOTING

    
막히면 여기부터

    

      
속도 1~3 tok/s 급락
→
CPU 오프로딩 · ollama ps 확인 후 3비트로

      
CUDA Out of Memory
→
컨텍스트↓ · -fa on · q8_0 · mmproj 언로드

      
GPU 미인식
→
최신 드라이버 · cudart 같은 폴더 · CUDA_VISIBLE_DEVICES=0

      
모델 목록 안 보임
→
서버 가동 확인 · /v1 · host.docker.internal

      
도구 호출 실패
→
--jinja · --tool-call-parser · 64K+ 컨텍스트

      
문맥 유실·무한 반복
→
컨텍스트 32K~64K+ · 권장 샘플링 값 적용
